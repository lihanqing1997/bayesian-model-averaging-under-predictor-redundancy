# Bayesian Model Averaging under Predictor Redundancy

This repository contains the R implementation used for the paper
`Bayesian Model Averaging under Predictor Redundancy`.

The code implements density-ratio posterior compression for a fixed support
posterior. The main workflow builds support-kernel dictionaries, estimates
kernel masses, optimizes mixture weights with a fallback component, and reports
held-out TV, forward KL, reverse KL, fallback weight, storage cost, and
diagnostic summaries.

## Repository Contents

- `sim/src/support_kernels.R` defines support kernels and support-region utilities.
- `sim/src/adaptive_support_kernel_compression.R` implements active-set and pooled-pruned compression routines.
- `sim/src/family_mixture_compression.R` implements the hard-region special case used by the support-kernel routines.
- `sim/src/family_dictionary.R` defines dictionary and storage-code helpers.
- `sim/src/support_kernel_benchmark.R` contains exact, large-p, logistic, and real-response benchmark helpers.
- `sim/exact_bma.R` and `sim/mcmc_bma.R` compute reference support posteriors in enumerable and sampled settings.
- `sim/comparison_methods.R` implements top-M, credible-set, posterior-clustering, dilution-prior, DPP-prior, and prediction-only comparison rows.
- `sim/run_support_kernel_unit_tests.R` runs source-level checks for the compression identities and optimizer diagnostics.
- `sim/run_support_kernel_competitor_benchmark.R` runs the exact dictionary benchmark.
- `sim/run_large_end_to_end_askpc_benchmark.R` runs the non-enumerable p=100 end-to-end benchmark.
- `sim/run_real_response_reduced_benchmark.R` runs the reduced exact real-response spectroscopy benchmark.

Generated tables, figures, checkpoints, and large posterior-draw objects are not
included in this lightweight code release. They are regenerated by the scripts.

## R Requirements

The scripts were developed with R 4.4.2. Install the main packages with

```r
install.packages(
  c("yaml", "glmnet", "grpreg", "pls", "coda", "boot", "SGL", "ggplot2"),
  repos = "https://cloud.r-project.org"
)
```

## Quick Checks

From the repository root, run

```sh
Rscript sim/run_support_kernel_unit_tests.R
Rscript sim/run_support_kernel_competitor_benchmark.R --mode=smoke
Rscript sim/run_large_end_to_end_askpc_benchmark.R --mode=smoke
Rscript sim/run_real_response_reduced_benchmark.R --mode=smoke --dataset=all
```

## Main Reproduction Commands

The exact dictionary benchmark is regenerated with

```sh
Rscript sim/run_support_kernel_competitor_benchmark.R --mode=full --checkpoint --workers=4 --chunk-size=8
Rscript sim/make_support_kernel_competitor_outputs.R --mode=full
```

The non-enumerable p=100 benchmark is regenerated with

```sh
Rscript sim/run_large_end_to_end_askpc_benchmark.R --mode=full --checkpoint
Rscript sim/run_large_end_to_end_askpc_benchmark.R --mode=summarize --publish
Rscript sim/make_large_end_to_end_askpc_outputs.R
```

The reduced real-response spectroscopy benchmark is regenerated with

```sh
Rscript sim/run_real_response_reduced_benchmark.R --mode=full --dataset=all
```

The logistic support-posterior check is regenerated with

```sh
Rscript sim/run_logistic_support_kernel_check.R --mode=full
```

## Notes

All commands assume that they are run from the repository root. Output files are
written under `sim/output/`, which is intentionally ignored by Git. Full
benchmarks can take hours on a workstation, while smoke modes are meant only to
check interfaces.
